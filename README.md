# Restaurant Management and Reservation System

Full-stack project using:

- Angular frontend
- Node.js / Express backend
- MongoDB database
- WebSockets / Socket.IO
- Docker

## Main user roles

### Customer
- Login / registration
- View menu
- View table availability
- Make a reservation
- View reservation status

### Admin
- Login
- Manage menu items
- Manage tables
- Manage reservations
- Receive real-time updates

## Project Structure

- `frontend/` - Angular client
- `backend/` - Node.js / Express server
- `docker-compose.yml` - distributed Docker setup
